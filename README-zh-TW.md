# 倍速時光屋｜影音加速器 繁體中文液態玻璃版

公開版識別：`0.11.1-zh-TW.1`。以官方 v0.11.1 為基底，保留每個播放器及不同分頁的速度隔離。

## 安裝或更新

1. 解壓縮 `倍速時光屋.zip`。
2. 開啟 `chrome://extensions`，啟用「開發人員模式」。
3. 按「載入未封裝項目」，選擇內含 manifest.json 的 `倍速時光屋` 資料夾。
4. 先停用原版、舊版或其他倍速外掛，再重新整理媒體網頁。

若已安裝舊版，想保留原本的設定，可把新版資料夾內的檔案覆蓋到原安裝資料夾，再於擴充功能頁按「重新載入」，接著重新整理媒體網頁。不要同時啟用兩個版本。

## Mac 風格設定頁

選項、提示、快捷鍵動作、匯入／匯出訊息與常見問題已改為繁體中文。設定頁改用較大的字體、圓角卡片、分段式導覽與藍色操作按鈕，並跟隨系統深色／淺色模式。

在「一般設定 → 液態玻璃外觀」可以：

- 拖曳「玻璃不透明度」滑桿，從 0% 到 100% 即時預覽。數值越低，底色越透明；文字與按鈕不會一起淡掉。
- 調整「控制器文字與按鈕大小」。這是按鈕的基準大小；倍速數字會另外放大約四成，並使用粗體。基準 14 時，倍速數字約為 20 像素。
- 儲存後重新整理媒體頁面，套用新的外觀。

背景模糊效果取決於控制器後方的畫面及網站的合成方式；有些頁面的模糊感可能較弱。0% 仍保留玻璃邊緣與文字；若要完全隱藏，請使用以下顯示設定。

## 顯示／隱藏

- 按 V 可隨時顯示／隱藏倍速控制器。
- 勾選「預設隱藏倍速控制器」，可讓控制器平常隱藏，需要時再按顯示熱鍵叫出。
- V 與其他熱鍵都可在「鍵盤快捷鍵」中自訂。

## 鍵盤快捷鍵順序與預設值

1. 降低倍數：A，每次降低 0.1 倍。
2. 提高倍速：D，每次提高 0.1 倍。
3. 重設倍速：S，預設目標為 1.0 倍，保留原有切換記憶。

這三項固定顯示在快捷鍵列表最前面。已儲存過的按鍵不會被覆蓋；更新後若仍顯示舊按鍵，可直接在前三項輸入 A、D、S 並儲存。若使用「還原預設值」，外觀及其他偏好設定也會一起還原。

## 操作與隔離

將滑鼠移到目標播放器，或點一下播放器／控制器後，使用 A／D 改速、S 重設切換、G 偏好倍速、Z／X 倒退快進。每個 video／audio 元素各自保留速度與切換記憶，不會讀取其他播放器的最後倍速。

新建立的播放器從網站原生速度或明確設定的網站起始倍速開始。重新整理或網站換成全新的 media DOM 元素時會重新開始；全域「最後速度套用到所有新播放器」功能保持停用。

## Spotify 與已知限制

音訊支援預設開啟。在可存取的 HTML5 audio／video 範圍內可控制 Podcast；DRM、非 HTML5 播放管線、封閉 shadow root、禁止注入的頁面或網站強制改速仍可能限制功能。本次未以 Spotify 線上帳號實播驗證。

網站持續強制改速時，沿用有限次重試與退讓機制；重新選取該播放器並設定倍速可重新啟用控制。iframe 內的快捷鍵需在該 frame 取得焦點，工具列的速度按鈕只控制主 frame。
